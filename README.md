# AppGuard

Android-приложение, которое не даёт двум выбранным приложениям работать одновременно.
Перед запуском одного из них AppGuard проверяет, работает ли второе. Если работает, принудительно
закрывает его (force stop) и только после этого открывает первое.

Root не нужен и не используется.

## Как это работает

| Задача | С Shizuku (рекомендуется) | Без Shizuku (только спецвозможности) |
|---|---|---|
| Проверить, работает ли второе приложение | `ps -A` — видит все процессы, включая фоновые | AppGuard сам помнит, открывалось ли приложение после последней остановки |
| Принудительно закрыть | `am force-stop <пакет>` с проверкой, что процесс исчез | Открывает «О приложении» и сам нажимает «Остановить» → «ОК» |

**Способы запуска:**

1. **Ярлык AppGuard** (кнопка «Ярлык»): на рабочем столе появляется иконка «Имя ⛨». При нажатии
   AppGuard сначала закрывает второе приложение и только потом открывает выбранное. Выбранное
   приложение не стартует, пока второе работает.
2. **Обычная иконка** (если включены служба спецвозможностей и «Перехватывать запуск»): AppGuard
   замечает, что приложение открылось, пока второе работает. Тогда он сворачивает его, закрывает **оба**
   и открывает нужное заново. Приложение на долю секунды успевает появиться, поэтому надёжнее
   запускать через ярлык.

## Установка

1. Скачайте APK из артефактов GitHub Actions (вкладка **Actions** → последняя сборка → `AppGuard-debug-apk`)
   или соберите сами: `./gradlew assembleDebug`.
2. Откройте AppGuard и выберите «Приложение 1» и «Приложение 2».
3. Настройте доступ одним из способов (лучше оба):

### Shizuku (без root)

1. Установите [Shizuku](https://shizuku.rikka.app/download/).
2. Запустите его по [инструкции](https://shizuku.rikka.app/guide/setup/): на Android 11+ через
   «Беспроводную отладку» прямо на телефоне, на более старых — один раз командой с компьютера по ADB.
   После перезагрузки телефона Shizuku нужно запускать снова.
3. В AppGuard нажмите «Дать разрешение».

### Служба спецвозможностей

1. В AppGuard нажмите «Настройки» в блоке «Служба спецвозможностей» и включите «AppGuard: закрытие приложений».
2. На Android 13+ для APK, установленного не из магазина, переключатель может быть недоступен:
   «Настройки → Приложения → AppGuard → ⋮ → Разрешить ограниченные настройки», затем включите снова.

Служба нужна для перехвата запуска с обычной иконки и как запасной способ закрытия, если Shizuku не запущен.

## Ограничения

- Без Shizuku AppGuard не видит фоновые процессы. Если второе приложение поднимется само в фоне
  (push-уведомление, автозапуск), без Shizuku это не заметить.
- Если второе приложение перезапустится в фоне, пока открыто первое, AppGuard узнает об этом
  при следующем переходе в одно из приложений пары.
- Режим без Shizuku ищет кнопку «Остановить» по тексту. На сильно изменённых прошивках
  (MIUI/HyperOS, One UI и т.п.) подпись может отличаться. Если кнопка не нашлась, запуск отменяется
  с сообщением об ошибке.
- Некоторые приложения могут сами обнаруживать включённую отладку по USB/Wi-Fi или включённые службы
  спецвозможностей. Это отдельная тема, AppGuard на это не влияет.

## Структура

- `Guard.kt` — основная логика: проверить → закрыть второе → открыть первое.
- `ShizukuShell.kt` — shell-команды через Shizuku.
- `GuardAccessibilityService.kt` — перехват запусков и нажатие «Остановить» в настройках.
- `LaunchActivity.kt` — невидимая точка входа для ярлыков.
- `MainActivity.kt`, `AppPickerActivity.kt` — интерфейс.
